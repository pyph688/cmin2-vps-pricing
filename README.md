## CMIN2 是什么线路，为什么移动用户都在问

CMIN2 是中国移动国际的第二代国际骨干网，ASN 是 AS58807。可以把它理解成移动网络内部的“VIP 车道”：更少的跳数、更少的拥塞，中国移动国内网络与海外之间的流量走这里优先中转。对应的普通线路是传统 CMI 国际出口，晚高峰的体验差距很明显。

背景是这样的：中国到美国方向，中国电信从 2019 年起停止了与联通、移动的对等互联，普通 163 骨干（AS4134）高峰期丢包率可以到 30% 以上，这对三家的用户都是灾难，移动方向尤其难伺候。搬瓦工在 2024 年 11 月给 USCA_6 和 USCA_9 的 E-commerce 套餐加入了 CMIN2 回程，社区测评普遍反映这明显改善了移动用户的吞吐表现——按多份公开测评的汇总数据，DC9 机房移动方向平均延迟约 174ms（国内最快节点 140ms 左右），CN2 GIA 回程路径丢包接近 0，2.5Gbps 端口套餐从国内实际能跑到 200–400 Mbps 下载，瓶颈通常是家里的宽带。

一个实用细节：怎么确认买到的机器真走了 CMIN2？在机器上 traceroute 看国内段经过的 AS 号，出现 **AS58807** 就是 CMIN2 精品网，这是业内公认的验证方法。

还要纠正一个常见误解：搬瓦工的“三网优化”里，CMIN2 只作用于移动方向的回程。电信用户走的是 CN2 GIA，联通用户走的是 Premium（AS10099），三网各走各的高端线。所以这套套餐对移动、电信、联通用户都有优化，只是“CMIN2”这个名字只挂在移动身上。
